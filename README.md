# Interacción humano-computador

Cómo perciben, piensan y se equivocan las personas frente a una interfaz, y cómo se investiga, prototipa, evalúa y mide un diseño: de la ley de Fitts y las heurísticas de Nielsen a los experimentos controlados y las interfaces con IA.

**Ver en línea:** https://aaramirez.github.io/interaccion-humano-computador/
